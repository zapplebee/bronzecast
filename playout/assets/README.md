# Fallback test card

`rtf-1953.jpg` is the user-selected RTF 819-line test card (1953), downloaded from:
https://upload.wikimedia.org/wikipedia/en/a/ac/RTF_Test_card_819-lines_1953.jpg

The playout service preserves this source image and transforms it at startup into
a muted ivory/green, stepped-tone, horizontal-scanline fallback frame.
Original image rights remain with the source rights holder; this repository does
not assign it a new license.
